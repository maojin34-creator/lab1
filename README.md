# Лабораторная работа 1. Численные методы решения СЛАУ

Реализация и сравнение методов решения систем линейных алгебраических уравнений на Python.

## Содержание

| Часть | Что сделано |
|---|---|
| Разминка | метод прогонки для трёхдиагональной матрицы, проверка точности, график времени от размера системы (проверка O(N)) |
| Основное блюдо | методы Якоби, Зейделя, верхней релаксации (SOR), а также наискорейшего спуска и сопряжённых градиентов на матрице `pyamg.gallery.linear_elasticity` (сетка 100x100, латунь) |
| Десерт | зависимость оптимального параметра релаксации ω от размера системы, точности и коэффициента Пуассона |

## Файлы

- `slau_lab.ipynb` — ноутбук с кодом, пояснениями, результатами и выводами (основной отчёт)
- `slau_lab.py` — тот же код одним скриптом (ячейки `# %%`, подходит для Spyder и VS Code)
- `requirements.txt` — зависимости

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows; на Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
jupyter lab                   # открыть slau_lab.ipynb и выполнить все ячейки
# или
python slau_lab.py
```

Через conda:

```bash
conda create -n slau python=3.12 -y
conda activate slau
conda install -c conda-forge numpy scipy matplotlib pyamg jupyterlab -y
```

Параметры расчёта (сетка `GRID`, точность `TOL`, лимит итераций `MAX_ITER`) заданы в начале файла. Для быстрой проверки поставьте `GRID = 30`. Полный расчёт на сетке 100x100 занимает несколько минут (самый долгий метод — Зейдель, около 25 секунд).

## Основные результаты

Матрица упругости 20000x20000 (сетка 100x100), относительная невязка `||b - Ax|| / ||b|| < 1e-6`:

| метод | итераций | статус |
|---|---|---|
| Якоби | 65 | расходится |
| Зейдель | 10176 | сошёлся |
| SOR, ω = 1.5 | 3386 | сошёлся |
| SOR, ω = 1.97 | 657 | сошёлся |
| наискорейший спуск | 20000 | не достиг точности |
| сопряжённые градиенты | 328 | сошёлся |

Оптимальное ω растёт с размером системы (1.44 для размера 128, 1.75 для 1152), стремясь к 2, и почти не зависит от требуемой точности. Подробные выводы приведены в конце ноутбука.
